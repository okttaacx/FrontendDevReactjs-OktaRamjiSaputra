# Frontend Developer Technical Test — Restaurant Directory App

Aplikasi direktori restoran interaktif yang dibangun pakai React.js dan Vite. Proyek ini memenuhi seluruh spesifikasi mockup, termasuk fitur client-side filtering (Open Now & Price), server-side filtering (Categories), serta halaman Detail View yang terintegrasi dengan Google Maps secara dinamis.

## 🌐 Link Proyek

- **Live (Netlify):** https://frontenddevreactjs-oktaramjisaputra.netlify.app/
- **GitHub:** https://github.com/okttaacx/FrontendDevReactjs-OktaRamjiSaputra

---

## 🛠️ Spesifikasi Environment

| Teknologi | Versi |
|-----------|-------|
| Node.js | v18.x / v20.x (LTS) |
| React.js | ^18.2.0 / ^19.0.0 |
| Build Tool | Vite |

## 🚀 Cara Menjalankan Proyek

### 1. Clone Repositori

```bash
git clone https://github.com/okttaacx/FrontendDevReactjs-OktaRamjiSaputra.git
cd FrontendDevReactjs-OktaRamjiSaputra
```

### 2. Install Dependensi

```bash
npm install
```

### 3. Jalankan Development Server

```bash
npm run dev
```

Buka browser dan akses `http://localhost:5173`
